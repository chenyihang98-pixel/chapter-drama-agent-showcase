# 模型与接口

本文列出章节短剧工作台按用途接入的五类模型服务、演示版本保存的模型设置，以及接入时遵循的原则。不包含任何密钥、账号信息或服务地址配置。

[← 返回首页](../README.md)

## 用途与服务

| 用途 | 服务方 | 接入方式 | 输入 → 输出 |
|---|---|---|---|
| 剧情与分镜 | 月之暗面 · Kimi | OpenAI 兼容的 Chat Completions 接口 | 原文、人物与方案 → 结构化结果（人物、剧情、台词、镜头） |
| 画面检查 | 阿里云 · 通义千问 | OpenAI 兼容的 Chat Completions 接口，图片输入 | 关键帧、参考图与镜头要求 → 逐项检查结果 |
| 人物与关键帧 | 火山引擎 · 火山方舟 | 方舟图片生成接口 | 文字描述（可带参考图）→ 图片 |
| 镜头视频 | 火山引擎 · 火山方舟 | 方舟视频生成接口，异步任务 | 首帧图片与镜头动作描述 → 视频片段 |
| 角色对白与旁白 | 火山引擎 · 豆包语音 | 豆包语音合成接口 | 台词文本与声线 → 音频 |
| 合成、字幕与导出 | 本地（不调用 AI 服务） | FFmpeg / ffprobe 与应用代码 | 视频片段、音频与字幕 → MP4 / SRT |

文字模型除了规划剧情与分镜，也用于文字层面的检查；画面检查模型逐项核对人数、外貌一致性、必要道具、场景、镜头关系和动作起点。

## 演示版本的模型设置

| 用途 | 保存的模型 ID |
|---|---|
| 剧情与分镜 | `kimi-k3` |
| 画面检查 | `qwen3.8-max` |
| 人物与关键帧 | `doubao-seedream-5-0-pro-260628` |
| 镜头视频 | `doubao-seedance-2-5-260628` |
| 角色对白与旁白 | `seed-tts-2.0` |

以上是制作《狼来了》演示版本时应用中保存的设置，与应用制作确认界面列出的“服务模型”一致。它们只说明这次演示用了什么，不代表服务方当前仍提供同名模型，也不保证其他账号或接口能直接兼容。

演示记录中的视频请求参数：图生视频（首帧为检查通过的关键帧），时长 8 秒，720p，不生成模型自带音频，保留服务方水印。

## 接入原则

- **按用途分别配置**：每种用途单独选择服务、模型和凭据，在应用的「服务连接」中管理。文字与画面检查通过 OpenAI 兼容接口接入，可以填写服务地址与模型 ID。
- **密钥不进项目**：配置中只记录凭据的引用名，密钥本身不写入项目数据或导出文件。
- **固定配置**：项目固定执行时使用的配置版本；配置被停用、删除或无法解析时拒绝发送，不自动改用其他模型。
- **发送前确认**：每一批付费请求发送前列出模型、新增调用次数上限和参考费用（估算值，不是账单）。
- **输出只是候选**：模型回复先按约定格式解析并经本地规则检查，通过后才保存为候选；画面检查给出的分数是视觉估计，不是身份认证，也不是准确率。
- **结果未知不重发**：已发送但结果未知的请求不会自动重发；另发新请求前需要确认原请求可能已被处理或计费。
