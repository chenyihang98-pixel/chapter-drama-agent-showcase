# 模型与接口

[← 返回首页](../README.md)

## 用途与服务

| 用途 | 服务 | 接入方式 | 输入 → 输出 |
|---|---|---|---|
| 剧情与分镜 | 月之暗面 · Kimi | OpenAI 兼容 Chat Completions | 原文与方案 → 人物、剧情、台词、镜头 |
| 画面检查 | 阿里云 · 通义千问 | OpenAI 兼容 Chat Completions（图片输入） | 关键帧与镜头要求 → 逐项检查结果 |
| 人物与画面 | 火山方舟 · Seedream | 图片生成 API | 文字描述（可带参考图）→ 人物形象、关键帧 |
| 镜头视频 | 火山方舟 · Seedance | 视频生成 API（异步任务） | 首帧图片与动作描述（开口镜头可附参考音频）→ 视频片段 |
| 角色配音 | 豆包语音 | 语音合成 API | 台词与声线 → 音频 |
| 合成与导出 | 本地 | FFmpeg / ffprobe | 视频片段、音频、字幕 → MP4 / SRT |

## 演示使用配置

| 用途 | 模型 ID |
|---|---|
| 剧情与分镜 | `kimi-k3` |
| 画面检查 | `qwen3.8-max` |
| 人物与画面 | `doubao-seedream-5-0-pro-260628` |
| 镜头视频 | `doubao-seedance-2-5-260628` |
| 角色配音 | `seed-tts-2.0` |

## 接入方式

- 每种用途单独配置服务、模型和凭据；文字与画面检查通过 OpenAI 兼容接口接入，可自定义地址与模型 ID。
- 凭据不写入项目数据或导出文件。
- 项目固定所用的配置版本；配置停用或删除时停止发送，不自动替换模型。
- 发送前按确认的制作范围核对所用模型与调用上限。
- 声音分两种来源：开口说话的镜头可由视频模型根据参考音频生成原生声音；旁白与其余台词使用选定的配音，在合成时按排时放入。
